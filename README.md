# Data-Driven Techniques

This repository is a collection of notebooks focused on data-driven system identification and filtering. It collects methods such like Dynamic Mode Decomposition (DMD), Hankel-DMD, Koopman Kalman Filtering (KKF), Ensemble Kalman Inversion (EKI), and Particle Filters. It includes exercises for analytical non linear systems, and a biomedical application case
